# Маленькая Якутия

Прототип маркетплейса якутских ремёсел (украшения, ножи, одежда, товары для дома, сувениры).

Статический одностраничный макет: фон стены и фото товаров сгенерированы, товары на странице — примеры для проверки раскладки, не реальный каталог.
